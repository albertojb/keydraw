# KeyDraw Roadmap

**Status:** Draft — 2026-09-15

## Epic 1 — Calm keyboard playground

Build and validate the complete local game experience: parent start screen, true fullscreen, any-key and multi-key input, varied ASCII-style objects, calm presentation, optional key invitations, and protected exit controls.

## Epic 2 — Accessibility and resilience

Test keyboard capture, fullscreen transitions, reduced-motion behavior, resize handling, rapid/palm input, focus recovery, and supported desktop browsers. Add clear fallback behavior where browser rules differ.

## Epic 3 — GitHub delivery foundation

Create the GitHub repository, document the game and safety limits, add automated static checks, establish `dev` as the default integration branch, and retain `main` as release-only production.

## Epic 4 — Cloudflare production release

Configure Cloudflare deployment, connect `keydraw.jbtcr.com`, verify HTTPS and production behavior, and document the release process.

## Epic 5 — Toddler observation pass

Observe real play without adding analytics, record only parent-reported friction, and tune pacing, object variety, prompts, and legibility while preserving the north star.
